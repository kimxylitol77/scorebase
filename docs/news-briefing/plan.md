# 해외 축구 브리핑 — 계획

> 2026-07-04. "진짜 축구를 좋아하는 커뮤니티" 첫 단추 — 찌라시 배제, 공신력 소스만.

## 무엇을

Tier 1 해외 소스(구단 공식·리그 공식·BBC·The Athletic 기자 단위·Sky Sports)의 축구
보도를 **사실 기반으로 한국어 재구성**해 커뮤니티 게시판에 자동 발행한다.
전문 번역이 아니라 보도 인용이므로 저작권 안전(출처·기자 명시 + 원문 링크 + 인용 1문장 이내).

## 왜

- 국내 커뮤니티는 찌라시·펨코발 재가공이 대부분 — 공신력 필터가 차별화 포인트.
- 브리핑 글이 곧 토론 스레드 시드 → 자유게시판·분석게시판과 같은 댓글/경험치 인프라 재사용.
- 과거 이적 루머 탭(7c9714d→810bbf4 철회)의 실패 원인(헤드라인만 haiku 단독 분류)을
  보완하는 재시도 조건 충족: **본문 포함 + 상위 모델(sonnet-5) + 2단계 검증**.

## 사용자 결정 (2026-07-04 확정)

1. 노출: 커뮤니티 새 카테고리 — /analysis 통합 게시판의 세 번째 보드 탭 `?board=briefing` (category BRIEFING)
2. 범위: 이적 + 주요 뉴스 전부 (부상·감독·구단 이슈 포함)
3. 발행: 자동 발행 + 텔레그램 사후 감시 (오보 시 원클릭 숨김 링크)

## 파이프라인

```
RSS 수집 (Tier1 화이트리스트, 48h 이내)
  → URL 해시 dedup (NewsBriefing 테이블, 전 항목 기록)
  → haiku 일괄 분류 (뉴스가치 0-10 · 카테고리 · 리그 · storyKey 클러스터)
  → 후보 선별 (score>=6, 스토리당 최고 tier 소스 1건, 런당 3건 · 일일 12건 캡)
  → 본문 fetch (직접 링크만, 실패 시 헤드라인+요약으로 진행)
  → sonnet-5 재작성 (한국어 브리핑 400~700자, 번역 금지 가드레일)
  → sonnet-5 검증 (원문 대조 — 날조·직역·표기 오류 시 REJECTED, 발행 안 함)
  → Post 발행 (category BRIEFING, 봇 계정 "스코어베이스 국제부") + 텔레그램 알림
```

## 법적 가드레일 (프롬프트 + 템플릿에 내장)

- 원문 번역·요약 금지 — 사실 추출 후 자기 문장 재구성 (2차적저작물작성권 회피)
- 직접 인용 최대 1문장, 따옴표 + 발화자 명시 (저작권법 28조 인용)
- 글 하단 고정: 출처 링크 + 기자명 + "사실 기반 재구성 브리핑, 전문 번역 아님" 고지
- 검증 단계에서 직역투 감지 시 발행 차단
