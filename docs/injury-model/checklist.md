### 검증 중 잡은 함정 두 개

**① af→ts 역매핑이 1:1 이 아니다.** af id 3,420개 중 131개에 ts id 가 둘 이상 붙어 있고
값이 갈리는 것도 있다(af 736 → 95분 / 933분). 그냥 덮어쓰면 마지막 것이 이겨 엉뚱한 기록을
쓴다 → **출전시간 많은 쪽**을 고르도록 수정(126/126 확인).

**② 표본이 얕은 팀에서 share 가 100% 로 튄다.** MLS 시즌스탯이 92명뿐이라 팀당 1~2명 →
후보까지 "팀 전력의 100%" 로 잡혔다. 그대로 쌓았으면 백테스트가 통째로 오염됐다.
→ `MIN_SQUAD_FOR_SHARE = 10`, 표본 얕으면 **share 를 내지 않는다**(null = 모른다).
수정 후 값이 1~4% 정상 범위로 돌아왔다.
