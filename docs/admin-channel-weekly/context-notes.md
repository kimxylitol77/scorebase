## 결정
- **원본 재판정 대신 일별 저장값 합산.** 잘림 없는 SQL 로 기간마다 판정하면 7일 6초·30일 23초·전체 41초(실측) — 렌더에 못 넣는다. 일별 방문자는 이미 `DailyTraffic` 에 하루 판정으로 저장 중이라(cron 00:10 KST) 같은 판정에서 채널 수만 더 저장한다.
- 판정 창은 하루. 기간 창 판정과 차이는 하루 몇 명 수준(9/17 방문자 423 vs 420 실측). 대신 확정된 날의 값이 이후 안 바뀐다.
- 방문자(unique)는 일별 고유 세션의 합 — 여러 날 들어온 같은 세션은 날마다 센다. 라벨에 명시.
- 지난주 대비는 **어제까지 7일 vs 그 전 7일**(온전한 날끼리). 오늘을 넣으면 반나절치와 온전한 7일을 비교하게 된다. 기존 "최근 7×24시간" 롤링은 일별 저장으로 재현 불가.
- 컬럼은 nullable JSONB — ADD COLUMN 은 메타데이터 변경이라 즉시. 배포 순서 = DDL → 백필 → 코드 배포(옛 코드는 새 컬럼을 무시).
