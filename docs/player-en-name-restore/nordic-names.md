## 대상 판정 — 국적으로 먼저 가른다

같은 철자라도 언어권이 다르면 규칙이 정반대다. 이걸 안 가르면 대량 개악이 난다.

|---|---|---|
| 노르웨이·덴마크·스웨덴·페로 | **h 묵음** (Hjalmar → 얄마르) | 규칙 교정 대상 |

| 알바니아·마케도니아·세르비아 | 별개 규칙 | 제외 |

아이슬란드어가 예외라는 건 ko위키 정본 `Hjörtur Hermannsson → 히외르튀르` 가 확증했다.
ISL 선수 5명 전부 h 를 살린 표기가 정상이라, 처음의 일괄 적용안대로 갔으면 이들이 전부 망가졌다.

## 적용 방침

1. **ko위키 langlink 정본은 국적 무관 무조건 채택.** 언어 규칙 판단이 필요 없다.
2. 위키가 없으면 **현재 값이 hj 규칙을 명백히 위반할 때만** haiku 음역을 쓴다.
3. 위반이 아닌데 haiku 가 손보자는 `Kj`·`Sj` 미세조정은 **전부 버린다**(보류 35건).
4. haiku 값을 쓸 때도 **위반 토큰만 갈아끼우고** 나머지 토큰은 현행 유지.

3·4는 실측 근거가 있다. haiku 는 `얄테 기츠`(정상)를 `알테 기츠`(j 탈락)로 되돌리려 했고,
같은 입력에도 `Andrew` 를 실행마다 앤드루/안드레로 다르게 냈다.

## 함정 두 개 (둘 다 조용히 실패한다)

- **Wikipedia API 는 User-Agent 없는 요청을 막는다.** 헤더가 없으면 예외가 아니라 빈 응답이 와서
  58건 전건이 "위키 문서 없음"으로 조용히 처리됐다. `scorebase-bot/1.0` UA 필수.
- **한글 범위는 `[하-힣]` 이어야 한다.** `[하-히]` 는 받침 있는 ㅎ 음절(`힐`·`혤`·`휼`)을 놓쳐
  "힐테 비드스트룹"·"욘 올라브 혤데"가 검사를 통과했다.

## 2차 — Kj·Sj·Skj 계열 (같은 날 이어서)

`hj` 만 보던 로직을 표기법 세칙 전반으로 일반화했다. **24건 추가 교정**.

### 언어별 규칙 (외래어 표기법 제3장)

| | 노르웨이어·스웨덴어 | 덴마크어 |
|---|---|---|
| `kj` | **"시" 계열** — Kjetil → 셰틸 | **"키" 계열** — Kjær → 키에르 |
| `sj`·`skj`·`stj`·`tj` | "시" 계열 — Skjelvik → 셸비크 | "시" 계열 — Sjælland → 셸란 |
| `gj`·`hj`·`lj`·`dj` | "이" 계열 — Gjøvik → 예비크 | 동일 |

`kj` 가 정반대인 게 핵심이다. ko위키 정본 `Simon Kjær = 시몬 키에르` 가 덴마크어 쪽 근거다.

### 판정은 초성·중성으로 — 규칙을 코드에 심었다

한글 음절을 분해해 검사하므로 받침·모음에 휘둘리지 않는다(예전 `[하-히]` 범위 버그가 구조적으로 못 생긴다).

- 초성 — `kj`·`sj` 토큰은 ㅅ, 덴마크어 `kj` 는 ㅋ, `gj`·`hj` 는 ㅇ.
- 중성 — 덴마크어 `kj` 는 **반드시 ㅣ**("크옐센"·"카에르고르" 처럼 k 와 j 를 떼어 적은 것도 위반).
- 중성 금지 — **ㅡ 로 끊으면 j 가 안 합쳐진 것**("스키엘비크"·"스쟈르비크"·"스촐드보르그").
  이 검사가 없으면 초성 ㅅ 만 보고 통과해버린다.

### 함정 하나 더 — locks 를 안 보면 되돌린다

수동 확정한 `욘 올라브 옐데` 를 ko위키 표제어 `혤데` 가 되돌리려 했다. **locks 등재분은 대상에서
먼저 빼야 한다.** 사람이 확정한 표기가 자동 로직보다 위다.

### ts 국적도 틀린다

`Kjartan Már Kjartansson`(명백한 아이슬란드 이름)이 **SWE 로 왔다**. 스웨덴 규칙을 적용하면
"샤르탄"이 되어 망가진다. 아이슬란드어에만 있는 글자(`á í ó ú ý þ ð`)가 보이면 국적을 무시하고
제외하도록 막았다. `é` 는 노르웨이 이름 `André` 에도 흔해 신호에서 뺐다.

### 사람이 직접 정한 것

haiku 가 규칙을 못 맞춘 셋은 손으로 지정하거나 동결했다.

- `Skjaerstein` — haiku 가 뒤를 독일식 "슈타인"으로 냈다 → **셰르스테인**
- `Skjoldborg` — o 를 ø 로 착각해 "셸"을 냈다 → **숄드보르그**
- `Malthe Kjølby` — haiku 가 쓰지 않는 음절("키옠비")을 냈고 덴마크어 kj+ø 확정 근거가 없어 **현행 동결**
- `Gjan ajdin` — 원본 이름이 깨졌고(성이 소문자, 어순 의심) 국적(SWE)과 이름 어원(발칸)이 충돌 → **동결**
- `Sjåtil` 2명 — "샤틸"/"시아틸"로 갈렸고 한쪽은 이름이 통째로 빠져 있었다 → **프레드릭 샤틸 · 하콘 샤틸**
