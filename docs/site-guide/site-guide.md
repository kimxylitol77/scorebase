스코어베이스에 있는 메뉴와 데이터를 한 페이지에 정리했습니다. 상단 메뉴 순서대로 따라가며, 각 항목은 해당 페이지로 바로 이어집니다. 이 글은 고정 안내라 메뉴가 바뀌면 함께 고칩니다.

## 먼저 알아둘 것 — 우리가 숫자를 말하는 방식

- **적중률**은 예측이 맞은 비율입니다. 배당을 무시하기 때문에 정배당만 찍어도 높게 나옵니다.
- **플랫 유닛 수익률**은 경기 시작 전 마지막 배당에 매 경기 1유닛을 걸었다고 가정한 후행 정산입니다. 배당에 북메이커 마진(약 5%)이 들어 있어 **장기 수익률은 마이너스가 정상 기대치**이고, 비교 기준선(매 경기 시장 인기픽에 걸기)보다 얼마나 덜 잃는지가 모델 신호의 크기입니다. 홈 첫 화면의 수익률 숫자가 이 값입니다.
- **CLV(종가 대비 가치)**는 내가 픽한 시점 배당을 킥오프 직전 종가와 비교한 값입니다. 양수가 꾸준하면 시장보다 먼저 좋은 값을 잡았다는 뜻입니다.
- 모든 확률·수익률은 통계 모델 기반의 참고용 정보입니다. 스코어베이스는 베팅을 중개하거나 권유하지 않으며, 배당은 시장의 예측치로서 분석·검증 대상으로만 다룹니다.
