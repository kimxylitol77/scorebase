# 농구 블라인드 드래프트 — 계획

작성 2026-09-27.

## 무엇을

NBA·KBL 역대 선수-시즌 카드를 이름·연도·포지션만 보고 5명 뽑아, 숨겨진 기여도 합으로
순위를 겨루는 게임. 경로 `/basketball/draft`. 착안은 databallr.com 의 SixRings.

## 왜

- SixRings 는 24시간 결과 3,130건이 쌓이는 검증된 형식이다 (2026-09-27 실측).
- KBL 원년(1997)부터의 선수-시즌은 해외 사이트에 없는 우리만의 재료다.
- `/career` 와 같은 "로그인 없이 바로" 동선으로 유입·체류를 만든다.

## 확정 결정 (사용자 답변 2026-09-27)

1. 리그는 NBA + KBL 두 모드.
2. 비회원도 플레이, 순위 등록은 회원만.
3. 1차 범위는 핵심 드래프트 + 찬스 + 리더보드 + 공유 카드. 일일 도전은 2차.

## 한 판의 규칙

- 판마다 무작위 한 구단의 선수-시즌 21장. 5판에서 1명씩 5명.
- 뽑으면 그 판 전체 수치가 공개되고 기여도 순으로 정렬된다.
- 슬롯은 가드 2·포워드 2·센터 1. 맞는 빈 슬롯이 없으면 그 카드는 못 뽑는다.
- 점수 = 5명 기여도(공격+수비) 합 + 보너스.
  - 풀 라인업 +3 (5슬롯 완성), 공수 균형 -2~+2, 내구성 -1.5~+1.5, 철벽 수비 +4.
- 찬스 6종 각 1회 (다시 뽑기·팀 바꾸기·포지션·더블 픽·전체 공개·시즌 섞기) + 돋보기 3회.
- 결과는 백분위로 반지 0~6개.

## 구조

| 층 | 내용 |
|---|---|
| 데이터 | `scripts/build-draft-pool.ts` → `data/draft-pool-{nba,kbl}.json` (빌드 타임, 런타임 외부 호출 없음) |
| 엔진 | `src/lib/draft/` 순수 함수 (시드 난수·판 생성·찬스·채점) + 단위 테스트 |
| 상태 | `DraftGame` 테이블 1개. 진행 상태·결과·리더보드·공유를 모두 담당. 수치는 서버에만 |
| API | `/api/draft` POST (start·pick·lifeline·next·finish) |
| 화면 | `/basketball/draft` (로비+게임), `/basketball/draft/result/[id]` (공유), OG 카드 |

## 검증

1. 풀 빌드 → 검증: 시즌·구단별 카드 수, 상위 카드가 상식과 맞는지 (조던·르브론·워니).
2. 엔진 → 검증: `npm test` 단위 테스트 (결정성, 슬롯 규칙, 찬스 1회 제한, 채점).
3. API·화면 → 검증: 로컬에서 한 판 완주, 응답에 미공개 수치가 없는지 확인.
4. 마무리 → 검증: `tsc`, 375px 화면, 리더보드·공유 카드 렌더.
