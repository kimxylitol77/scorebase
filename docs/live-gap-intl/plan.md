# 배구·국제대회 야구 라이브 갭 메우기 — 계획

2026-09-27 조사(배구·야구 서브에이전트 보고) 결과 중 "코드가 막고 있던 것"을 연다. AI 코멘터리는 사용자 지시로 제외.

## 1차 (하)
1. 야구 가짜 주자·아웃 제거 — ts detail_live extra 가 {} 인데 "주자 없음·0아웃" 으로 그림(카드·상세).
2. 배구 통계 라벨·비율 — stat 6~11 뜻 정정(브레이크 득점·사이드아웃 득점), 8·11 ×100.
3. 배구 서브권 — detail_live score[2](1=홈·2=원정) 카드·상세 표시.
4. 동적 야구 상세 H2H 좌우(swapSides)·AiMatchupCard allowDraw=false.
5. 야구 라이브 배당 수집 대상 KBO·NPB·MLB → 야구 전 리그.

## 2차 (중)
6. 배구 종료 경기 통계 백필 — ts match/live/history 로 종료 직후 최종 score·stats 덮어쓰기.
7. 배구 세트별 통계 탭(stats[1..n]).
8. 국제대회 야구 모델 예측 — pick-readiness 선발 대기를 선발 소스가 있는 리그로만, 동적 야구 상세에 결론 카드.
