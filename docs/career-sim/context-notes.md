# 축구선수 인생 시뮬레이터 — 컨텍스트 노트

작성 2026-08-27. 결정과 근거를 계속 덧붙인다.

## 왜 만드는가

경쟁사 copero.com.ar 의 `simulador-carrera` 를 직접 플레이해보고 착안.
기존 `/dream-team` 은 사실상 죽어 있다(회원 117명 중 팀 3개, 최근 30일 활동 0,
마지막 활동 2026-06-29). 드림팀은 **동결**하고 새 게임을 별도 경로로 만든다.

## 드림팀이 죽은 이유 = 이 게임에서 반드시 피할 것

실측으로 확인한 3가지.

1. `src/app/dream-team/page.tsx:20` 에서 비회원을 즉시 로그인으로 리다이렉트.
   처음 온 사람이 구경조차 못 한다. → **이 게임은 로그인 요구 안 함.**
2. `sitemap.ts` 에 드림팀 URL 이 한 줄도 없다. 검색 색인 불가. → **sitemap 등록.**
3. 진입 링크가 `/soccer` 칩 1개 + 커뮤니티 글쓰기 폼 1개뿐. → **정식 동선 연결.**

추가로 `/dream-team/free` 는 응답이 6.8~27.9초다. 원인은 `data/dream-pool.json`
(1.0MB, 선수 1,565명)을 매 요청 서버에서 읽어 전량 클라이언트로 넘기는 구조.
→ **이 게임은 서버 렌더에 큰 JSON 을 태우지 않는다.**

## 기술 결정

- **클라이언트 100%.** copero 도 네트워크 확인 결과 게임 진행 중 서버 호출이 0이었다.
  DB·API 없이 정적 JSON 만으로 돈다. 서버 비용 0, 로그인 불필요, 응답 즉시.
- **경로 `/career`.** dream-team 과 분리해 한쪽 운명이 다른 쪽에 영향을 주지 않게 한다.
- **구단 데이터는 빌드 타임 생성.** `scripts/build-career-clubs.ts` 가 Team 테이블에서
  `data/career-clubs.json` 을 만든다. 런타임에는 DB 를 건드리지 않는다.

## 구현하며 새로 알게 된 것 (2026-08-27)

- **구단 JSON 을 `import` 하면 tsc 가 죽는다.** 978개 리터럴을 타입 추론하다 힙을 터뜨렸다.
  그래서 `public/career-clubs.json` 에 두고 런타임 fetch 로 바꿨다. 초기 페이지도 가벼워진다.
- **이 저장소의 `tsc` 는 원래 기본 힙(4GB) 경계에 걸쳐 있다.** career 파일을 전부 빼고 돌려도
  OOM 이 났다. 내가 만든 문제가 아니다. 검증은 `NODE_OPTIONS=--max-old-space-size=8192` 로 한다.
- **팀 로고는 `<img>` 로 쓴다.** `TeamBadge` 가 그렇게 하고 있고 remotePatterns 를 건드릴 필요가 없다.
  `// eslint-disable-next-line @next/next/no-img-element` 를 같이 붙여야 린트가 통과한다.
- **페이지 title 에 `| Scorebase` 를 넣지 말 것.** 루트 layout 이 `template: "%s | Scorebase"` 로
  이미 붙인다. (참고: `/dream-team` 은 이 실수가 있어 제목이 두 번 붙는다 — 이번 범위 밖이라 두었다.)
- **일부 구단 로고는 api-sports 의 "이미지 없음" 대체 PNG 다.** URL 은 200 을 주므로 링크 검사로는
  안 잡힌다(표본 41개 전부 200). 용인 시티가 그 예. 소수라 그대로 두었다.

## 3단계 공유 설계 (2026-08-27)

게임이 서버·DB 를 안 쓰므로 **결과를 저장할 곳이 없다.** 그래서 공유 링크 자체를 기록으로 삼는다.
결과를 URL 쿼리에 담고, 받는 쪽 `/career/result` 가 그걸 읽어 카드와 페이지를 그린다.

- **base64 인코딩을 쓰지 않았다.** 한글이 섞이면 `btoa` 가 깨지고, 브라우저·노드 양쪽에서
  도는 인코더를 직접 짜야 한다. 평범한 쿼리 파라미터가 짧고 안전하고 디버깅도 쉽다.
- **URL 값은 절대 믿지 않는다.** 누구나 고쳐서 카드에 아무 숫자나 띄울 수 있다.
  `parseShareParams` 가 범위를 강제하고, 구단명은 제어문자를 지우고 24자로 자른다.
  국적·포지션이 목록에 없으면 아예 거부(페이지 404 · OG 400).
- **`/career/result` 는 noindex.** 파라미터 조합이 무한이라 색인되면 쓰레기 URL 이 쌓인다.
  대신 `follow` 는 열어둬 "나도 해보기" 링크가 `/career` 로 신호를 넘긴다.
