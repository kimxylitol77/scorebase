## 구현·검증 (같은 날)
- 9개 축구 리그 dry-run: EPL(아스널-첼시)·LALIGA(발렌시아-바르셀로나)·SERIE_A(인터-나폴리)·LIGUE_1(렌-마르세유) 블록 생성, BUNDESLIGA·UCL 은 7일 내 경기 없음(A매치 휴식기), K리그1·J1·MLS 는 점유·슈팅 스탯이 5경기 중 1~2경기라 게이트 탈락 → 섹션 없이 기존대로 발행. 의도된 동작.
- xG 는 표본 3경기 미만이면 줄을 생략(렌 1경기 2.66/2.98 처럼 한 경기 값이 평균으로 둔갑).
- "최근 5경기"는 리그 내 종료 경기라 시즌 초엔 지난 시즌 말 경기가 섞인다. 라벨이 "최근 5경기"라 거짓은 아니지만, 라운드 3~4 구간엔 지난 시즌 포메이션이 다수일 수 있다.
- EPL 실제 LLM 1회 생성(DB 쓰기 없음): 전술 섹션은 세 축 각 2~3문장, 데이터 밖 수치 없음. 포메이션 일반론("4-2-3-1 은 수비형 MF 2명")은 사실 창작이 아니라 해석으로 허용.
- **호스트 글의 기존 문제(이번 변경과 무관, 미수정)**: ① 시즌 필터가 없어 `prisma.match.findMany({ where: { league } })` 가 지난 시즌 경기까지 합산 → 9월 초 글이 "28승 7무 5패 91점, 시즌 막바지" 라고 지난 시즌 순위표를 서술. ② 강등 시뮬에 "팀 1540·팀 610697" 처럼 이름 없는 팀 id 노출(Team.league 라벨과 매치 팀 불일치). 둘 다 preseason-last-season-surfacing·team-league-label-rollover 메모리와 같은 계열 — 별건으로 처리할 것.

## 호스트 글 별건 수정 (같은 날)
- 시즌 경계 필터: `currentSeasonStart(league)` 이후 경기만 순위·시뮬에 쓰고, 새 시즌 일정조차 없을 때만 지난 시즌으로 폴백(predictions/[league] 와 동일 규칙). Elo 만 `eloMatches: allMatches` 로 시즌을 넘어 누적 — 시즌 초 3라운드 Elo 로 빅매치를 고르면 무의미해서 `buildSeasonContext` 에 옵션을 추가했다.
- 고아 팀 보강: 매치에 등장하는데 `Team.league` 라벨이 다른 id 를 id 로 재조회. 시즌 필터 후엔 EPL·LALIGA·KBO·MLB 모두 고아 0, 프롬프트에 "팀 N" 0건.
- 부작용: 시즌 초엔 FINISHED 30경기 게이트에 걸려 몇 주 스킵된다(EPL 지금 21경기 → 이번 주 스킵, LALIGA 31 통과). 지난 시즌 표를 "시즌 막바지"로 쓰는 것보다 스킵이 낫다고 판단. 게이트 완화는 별도 결정.
- 비시즌 스킵 게이트(마지막 경기 14일+·예정 없음)는 리그 전체 경기로 그대로 판정한다.
