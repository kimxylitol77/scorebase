# ANALYSIS 글 "이번 주 주목할 전술 포인트 3가지" — 계획

## 무엇을
리그 시즌 종합 분석(ANALYSIS, 색인되는 유일 글 타입)에 다가오는 빅매치 1경기를 골라
포메이션·템포/압박 성향·세트피스 세 축을 각 2~3문장으로 구조화한 H2 섹션을 붙인다.

## 왜
유튜브 전술 채널(GED FOOTBALL·엘미하의 전술노트)이 흡수하는 전술 학습 수요를
검색 가능한 텍스트로 받는다. 영상은 아카이브·검색에 약하고 우리는 매주 자동 축적된다.

## 해석 결정
- 백로그 문구는 "이번 경기"지만 ANALYSIS 는 리그 단위 글이다. 매치 단위 글(PREVIEW)은 noindex 라
  SEO 목적에 안 맞고, TACTICAL 타입은 경기 후·기본 OFF 상태다. 따라서 ANALYSIS 안에
  "이번 주 빅매치 1경기"를 골라 붙이는 방식으로 간다. 리그당 주 2회 발행이라 자연히 아카이브가 쌓인다.
- 대상 경기 = 향후 7일 내 예정 경기 중 Elo 합 최대 1경기(season-context 와 같은 Elo).

## 데이터 (있는 것만 쓴다)
- 포메이션: 라인업 JSON `formation` (최근 5경기 최다 사용 + 횟수)
- 템포·압박 성향: fixtureStats 점유율·슈팅(우리/상대)·파울 평균 — **압박 강도 직접 지표(PPDA)는 없음**을 프롬프트에 명시, 수치 창작 금지
- 세트피스: 코너킥 획득/허용 평균 (fixtureStats, 없으면 MatchStats) — 세트피스 득점 데이터 없음 명시
- xG 획득/허용 평균 (있을 때)

## 게이트 (얇은 글 방지)
축구 리그만. 양 팀 모두 최근 종료 경기 스탯 3경기 이상 + 포메이션 1경기 이상.
미달이면 섹션 자체를 붙이지 않는다(기존 글과 동일하게 발행).
