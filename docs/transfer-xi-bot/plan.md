# 이적시장 예상 XI 봇 (transfer-xi) — 계획

## 무엇을

이적시장 기간, 최근 48h 이적 활동이 가장 활발한 팀을 골라 "영입 반영 예상 베스트 XI" 글을
전술판(단일 photo 보드)과 함께 커뮤니티 페르소나(축덕광, post 875 작성자) 명의로 하루 1개 발행.

## 왜 이번엔 되는가 (과거 두 번 실패의 교훈)

- 1차(시장가치 버킷): 중앙 자원만 몰림 → 폐기 (post 991)
- 2차(웹 검색 슬롯 배정): LLM 이 엉뚱한 포지션에 배치 → 제거 (d718d43)
- 3차(이번): **역할 분리** — 웹 검색은 "누가 선발이냐"(이름 11개)만, "어디에 서느냐"는
  data/player-positions-detail.json(실제 라인업 x/y 좌표 도출, 7,800명, 주간 자동 갱신)이 결정.
  선수 id 가 클럽 이동에도 불변이라 신규 영입도 전 소속 경기 좌표로 세부 포지션 확보.
  검증: 맨시티 스쿼드 26/32 보유, 그릴리시 LW·마테우스 누네스 RB 등 스쿼드 문자보다 정확 실측.

## 파이프라인

1. 포커스 팀: FootballTransfer 48h, 이적료+시장가치 가중 1위 (스쿼드 데이터 보유 팀, 7일 내 발행 팀 제외)
2. 웹 검색 #1: 예상 XI 영문 이름 11개 (포지션 배정 금지)
3. 이름→id 매칭 (스쿼드+영입 기록, 정규화 매칭) — 9/11 미만이면 발행 스킵
4. 세부 포지션 조회 → 라인 버킷(GK/DF/DM/CM/AM/FW) → 풀피치 균등 배치, 포메이션 역산
5. 웹 검색 #2: 전술 분석 본문 3~4문단 (축덕광 톤, 금액·수치 창작 금지)
6. 발행: fake13 계정, FREE/soccer, lineupCode 첨부, createdAt 지터
