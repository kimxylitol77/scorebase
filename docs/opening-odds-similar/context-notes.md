# 오프닝 배당 유사경기 카드 — 컨텍스트 노트

## 출처

2026-07-30 AI 회사 회의(`ai-company/data/sessions/2026-07-30/144037auto.json`) PM 결론 P0.
원안은 competitor-scout 가 ScoreUp(Play Store) 화면에서 관찰한 아이디어.

> 배당 오프닝 유사 경기 비교 카드: 현재 경기의 오프닝 배당과 유사한 과거 경기를
> 자동으로 불러와 홈승/무승부/원정 결과를 보여준다

## 결정 1 — 야구 3리그(MLB·NPB·KBO) 한정. 축구는 표본 미달로 보류.

원안은 종목을 명시하지 않아 축구를 포함하는 것으로 읽혔다.

최근 60일 `Match.openingMarketHome` 채움률 실측 (2026-07-30).

| 리그 | 오프닝 | 현재 배당 | 전체 |
|---|---|---|---|
| MLB | 699 | 695 | 1569 |
| NPB | 234 | 234 | 534 |
| KBO | 205 | 205 | 396 |
| EPL·LALIGA·SERIE_A·BUNDESLIGA | 0 | 0 | 1612 |

**주의 — 최근 60일 창만 보면 축구를 "0건"으로 오판한다.** 전체 기간으로 다시 재면
축구에도 데이터가 있다.

| 리그 | 오프닝/전체 | 캡처 기간 |
|---|---|---|
| WORLD_CUP | 97/104 | 2026-05-28 ~ 07-15 |
| MLS | 61/435 | 2026-05-16 ~ 07-26 |
| LALIGA | 20/830 | 05-16 ~ 05-18 |

| LIGUE_1 | 8/654 | 05-16 |
| UCL | 1/239 | 05-16 |
| BUNDESLIGA | 0/648 | — |

빅5는 지난 시즌 막바지 사흘(5/16~5/18)만 잡혔고 그 뒤 시즌 오프로 경기가 없었다.
최근 60일이 0인 것은 수집 실패가 아니라 **경기 자체가 없었기 때문**이다.

그래도 결론은 유지된다 — 빅5 표본이 리그당 8~20건이라 `MIN_SAMPLE = 20` 을 넘지
못해 카드가 뜨지 않는다. WORLD_CUP 은 97건으로 충분하지만 대회가 7월에 끝나 대상
경기가 없다.

→ **8월 EPL 개막 후 재검토할 것.** 축구 배당 수집이 정상 작동하면 표본이 쌓이므로
`OPENING_SIMILAR_LEAGUES` 에 리그를 추가하면 된다. 3-way(무승부 있음)라 카드의
2분할 표시와 판정 문구를 축구용으로 손봐야 한다.

## 결정 2 — 유사도는 오프닝 홈 implied 확률의 ±밴드.

`openingMarketHome` 은 vig 제거된 implied 확률(0~1)이다. 같은 리그·종료 경기 중
대상 경기와 오프닝 홈확률이 가까운 것을 유사 경기로 본다.

유사경기 풀 (종료 + 오프닝 + 스코어 보유, 2026-07-30 실측).

| 리그 | 풀 크기 |
|---|---|
| MLB | 878 |
| NPB | 292 |
| KBO | 268 |

구간별 시장 implied vs 실제 홈승률 — 카드가 정보 가치를 갖는지 확인한 실측이다.

```
MLB  bucket5 시장 0.527 → 실제 0.525   (거의 일치)
MLB  bucket7 시장 0.623 → 실제 0.544   (시장이 홈 과대평가)
KBO  bucket4 시장 0.475 → 실제 0.378   (시장이 홈 과대평가)
KBO  bucket6 시장 0.568 → 실제 0.615   (시장이 홈 과소평가)
NPB  bucket7 시장 0.630 → 실제 0.706
```

구간에 따라 시장과 실제가 최대 10%p 어긋난다. 단순히 배당을 되풀이하는 카드가
아니라 실제 결과 분포를 보여주는 값이 있다.

## 결정 3 — 배당에는 무승부가 없지만 결과에는 있다. 따로 센다.

`openingMarketDraw` 는 야구 3리그 전 row 가 **0** (MLB 899/899, NPB 307/307,
KBO 268/268 실측). The Odds API 야구 h2h 가 2-way 라 draw outcome 이 없다.

그러나 **실제 결과에는 무승부가 있다** — KBO·NPB 는 연장 후 무승부를 인정한다.
오프닝 배당 보유 종료 경기 실측.

| 리그 | n | 홈승 | 원정승 | 무승부 |
|---|---|---|---|---|
| MLB | 878 | 446 | 432 | 0 |
| KBO | 268 | 130 | 131 | 7 |
| NPB | 292 | 148 | 137 | 7 |

무승부를 원정승에 합치면 수치가 틀어지므로 별도 집계한다. 실제 홈승률은
무승부를 분모에 포함해 계산하고(홈승 / 전체), 카드에 무승부 건수를 함께 노출해
사용자가 직접 판단할 수 있게 한다. MLB 는 0건이라 배지를 숨긴다.

## 결정 4 — 극단 오프닝값은 오염이므로 제외한다.

MLB 오프닝 홈확률 범위가 0.046~0.978 로 야구 현실 범위를 벗어난다. 실측 6건.

```
match 512508  oh=0.978 → 실제 6-8 홈 패
match 363858  oh=0.046 → 실제 3-2 홈 승
match 1724    oh=0.899 → 실제 0-2 홈 패
match 1715    oh=0.838 → 실제 3-7 홈 패
```

야구 프리매치는 최강 vs 최약도 홈 implied ~0.70 이 상한이다. 위 값들은 in-play 배당
누수 또는 오매핑으로 굳은 것 (관련 메모리 `odds-inplay-mismatch`).
`fetch-odds.ts` 의 `implied > 0.97` 가드는 나중에 추가돼 그 전 데이터가 남아 있다.

→ 표시 계층에서 오프닝 홈확률 **0.25~0.80** 밖은 유사경기 풀에서 배제하고,
대상 경기 자체가 범위 밖이면 카드를 렌더하지 않는다. 수집 데이터 정정은 별건.

## 결정 5 (2026-08-02) — 결정 3 의 "무승부를 분모에 포함" 을 철회한다.

결정 3 은 실제 홈승률을 `홈승 / 전체` 로 계산했다. 그런데 같은 카드가 바로 위
막대에 놓는 `marketAvgImplied` 는 결정 3 스스로 확인했듯 **무승부가 없는 2-way**
확률이다(`openingMarketDraw` 전 row 0, 홈+원정 합 = 1.00000 재실측 2026-08-02).
분모가 다른 두 값을 나란히 놓고 그 차이로 "시장이 홈을 과대평가/과소평가했다" 는
결론 문구를 냈으므로, 무승부가 있는 KBO·NPB 는 결론이 구조적으로 "과대평가" 쪽으로
치우쳤다.

렌더 가능한 전 표본 스윕 실측 (평균 gapPoints).

| 리그 | 렌더 N | 무승부 분모 포함 | 무승부 분모 제외 | 표본 평균 무승부율 |
|---|---|---|---|---|
| MLB | 936 | -1.54%p | -1.54%p | 0.00% |
| KBO | 285 | -1.80%p | -0.27%p | 3.23% |
| NPB | 319 | -1.42%p | +0.62%p | 3.85% |

결론 문구 임계가 ±3%p 라 이 편향은 실제로 문구를 바꾼다 — KBO 27/285(9.5%),
NPB 60/319(18.8%) 가 다른 문구로 뒤집힌다. MLB 는 무승부 0 이라 변화 없음.

실례. `/live/kbo/181931` 은 홈승 29 / 원정승 31 / 무승부 5 인데
"시장이 홈을 4.3%p 과대평가했다" 로 렌더되고 있었다. 무승부를 뺀 29/60 = 48.3% 는
시장값 48.9% 와 사실상 같아 "대체로 일치" 가 맞다.

→ `actualHomeWinRate` 를 `홈승 / (홈승+원정승)` 로 바꾸고 분모를 `decisiveSample`
로 노출한다. 무승부 건수 배지는 그대로 두고(결정 3 의 취지 유지), 무승부가 있을
때만 막대 라벨에 "(무승부 제외)" 와 각주를 붙여 기준을 명시한다.
