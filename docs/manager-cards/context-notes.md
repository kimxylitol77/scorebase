# 결정 기록

- 2026-09-28 엔진은 satori 유지. 새 의존성 없이 기존 폰트·캐시 헤더·이미지 로더(`weekly-frame.tsx`)를 재사용한다.
- 프레임은 새로 만든다. 기존 `Frame` 은 흰 글씨 고정이라 라이트 테마를 못 쓴다.
- 시즌 기록·리그 순위는 글에 저장돼 있지 않아 DB 경기에서 계산한다(시즌 시작 7월 1일 ~ 해당 월 말).
- 경쟁 후보의 감독 이름은 검증된 출처가 없어 카드에는 팀 이름만 쓴다.
- 링 카드 숫자는 116px. 150px 에서는 "100%" 가 원을 넘쳤다.
- 경기 기록 카드는 경기 수(3·4·5 이상)에 따라 줄 높이를 바꾼다. A매치 기간이 낀 달은 3경기뿐이라 고정 높이면 아래 절반이 빈다.
- 로컬 렌더는 장당 30~70초 걸렸다. dev 서버가 Neon 연결 풀을 같이 써서 그렇고, 데이터 로딩이 실패하면 폴백 카드(40KB 안팎)가 나온다. 샘플 생성 스크립트는 용량 60KB 미만이면 다시 받는다.
- 샘플 12장은 `samples/` 에 보관(글 #5687 기준, 2026-09-28 생성).
