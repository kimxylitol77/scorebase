# 아시안게임 허브 /asian-games — 계획

## 무엇을
2026 아이치·나고야 아시안게임(9/19~10/4) 우리가 수집하는 7개 대회를 한 페이지로 묶는다. 월드컵 허브(/world-cup)처럼 ?view= 탭.

- 한국 (기본) — 대회별 한국 대표팀 성적(승패)·최근 결과·다음 경기
- 일정·결과 — 7개 대회 전 경기를 날짜별로(KST), 오늘 먼저
- 종목별 — 대회 카드 7장(진행 경기 수·남은 경기·한국 성적·리그 페이지 링크)

## 왜
대회 페이지가 /leagues/ASIAN_GAMES_* 7개로 흩어져 있어 "아시안게임" 한 번에 볼 곳이 없다. 9/27 남자배구 누락도 전체를 보는 화면이 없어서 늦게 발견됐다.

## 범위 밖
- 메달 집계 — 우리 데이터 원천(TheSports)에 없다. 5개 종목만 있어서 만들면 틀린 표가 된다.
- 순위표 재구현 — 종목별 규칙(배구 세트·승점)이 달라 리그 페이지 것을 링크로 쓴다.
- 핸드볼·탁구 등 — TheSports 권한 없음.
