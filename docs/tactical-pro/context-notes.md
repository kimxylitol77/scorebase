## 결정과 근거

- **EPL 을 ts 재료 게이트로 옮긴다.** af xG 가 안 와서 기존 게이트로는 후보가 0이다. EPL 9/05 이후 글이 없던 이유로 보인다.
- **해석에 쓰는 숫자는 코드가 만든다.** "롱볼 비중 12%" 같은 파생값을 모델에게 계산시키면 틀린다. 코드가 계산해 블록으로 주고 모델은 서술만.
- **없는 데이터로 그리지 않는다.** 패스맵·평균 위치는 재료가 없어 도식에서 뺀다. 형태 도식은 "배치"라고 표기한다.
- **도식은 서버 SVG 컴포넌트.** 기존 `{{tactical-shape}}` 방식 그대로 본문 토큰 자리에 렌더. 데이터는 렌더 시점에 캐시에서 읽는다.
- **유튜브 영상은 내려받지 않았다.** 파일 다운로드는 사용자 확인이 필요한 동작이고, 형식(명제 → 구조 → 장면 → 숫자 → 결론,
  단순한 피치 도식에 화살표와 번호)은 널리 알려져 있어 구성만 따왔다. 특정 영상의 내용·문장은 쓰지 않는다.

## 2026-09-28 구현 중 결정

- **모델은 claude-sonnet-5.** Haiku 첫 생성은 "유효 슈팅 6회로 8회를 능가", 골 순서 혼동, 직접 계산한 비율 같은 논리 오류가 나왔다. 전술 글은 주 몇 편이라 비용 차이가 작다. `TACTICAL_PRO_MODEL` 로 바꿀 수 있다.
- **분량 2,600~3,200자, maxTokens 8192.** 4096 에서는 본문이 중간에 잘렸다.
- **사실 검증 확장.** 3 초과의 "N회·개·골·번"이 데이터에 없으면 탈락, 탈락 사유를 알려 1회 재작성.
- **EPL 은 ts 데이터로 후보에 넣는다.** af 에 xG 가 안 와 기존 게이트로는 후보가 0 이었다(`TS_TACTICAL_LEAGUES`).
- **초안 미리보기는 관리자 경로에 따로.** 글 페이지에 cookies() 를 넣으면 ISR(revalidate 600)이 깨진다. `/admin/articles/preview/[id]`, 본문 렌더는 `TacticalBody` 공용.
- **골 장면 도식의 선수 이름은 피치 밖 순서 줄로.** 피치 위에 얹으면 375px 에서 가장자리가 잘리고 가까운 선수끼리 겹쳤다.
- **Markdown 의 물결표 하나는 취소선이 아니다**(`singleTilde: false`). "1~15분" 구간 표기가 줄 그어졌다. 사이트 전체 글에 적용된다.
- **이달의 감독 선정식.** `경기당 승점 + 0.5 × (경기당 승점 − 기대 경기당 승점) + 경기당 득실차/100`. 기대 승점은 경기 전 predHome/Draw/Away. xG 는 26-27 에 오지 않아 뺐다. 성적이 먼저고 초과 성과는 비슷한 성적끼리 가른다(`manager-select.ts`).
- **첫 초안에서 본 실수.** 화면에 없는 "대시보드의 기대 승점" 언급, 경쟁 후보 초과 성과를 직접 뺄셈, 월간 순위를 리그 순위로 표기. 프롬프트에 세 가지를 명시하고 경쟁 후보의 초과 값도 데이터로 넘긴다.
- **남은 한계.** 패스맵·실측 평균 위치·xG 없음. 형태 도식은 선발 배치 좌표. 감독명은 af 값이라 월중 교체를 못 잡을 수 있고, 웹 리서치 내용(퇴장·기록 등)은 코드가 검증하지 못하므로 발행 전 사람이 확인한다.
