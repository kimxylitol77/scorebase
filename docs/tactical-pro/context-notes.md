## 결정과 근거

- **EPL 을 ts 재료 게이트로 옮긴다.** af xG 가 안 와서 기존 게이트로는 후보가 0이다. EPL 9/05 이후 글이 없던 이유로 보인다.
- **해석에 쓰는 숫자는 코드가 만든다.** "롱볼 비중 12%" 같은 파생값을 모델에게 계산시키면 틀린다. 코드가 계산해 블록으로 주고 모델은 서술만.
- **없는 데이터로 그리지 않는다.** 패스맵·평균 위치는 재료가 없어 도식에서 뺀다. 형태 도식은 "배치"라고 표기한다.
- **도식은 서버 SVG 컴포넌트.** 기존 `{{tactical-shape}}` 방식 그대로 본문 토큰 자리에 렌더. 데이터는 렌더 시점에 캐시에서 읽는다.
- **유튜브 영상은 내려받지 않았다.** 파일 다운로드는 사용자 확인이 필요한 동작이고, 형식(명제 → 구조 → 장면 → 숫자 → 결론,
  단순한 피치 도식에 화살표와 번호)은 널리 알려져 있어 구성만 따왔다. 특정 영상의 내용·문장은 쓰지 않는다.
