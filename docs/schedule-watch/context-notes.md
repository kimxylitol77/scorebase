# schedule-watch — 결정 노트

- **health-check 에 안 넣고 별도 cron.** health-check 는 하루 1회·180초에 탐지기 25개라 여유가 없고, 이 감시는 af 날짜 피드(하루 1콜 × 10일)를 불러 6시간 주기가 맞다. 루프 원칙(재검증 통과만 성공·key 당 상한·에스컬레이션·멱등 비파괴만 자동)은 self-heal.ts 와 동일하게 따른다.
- **자동 치유는 두 가지뿐.** (A) af 수집 리그의 빠진 경기 → collect 재실행(순수 fetch→upsert). (D) af 행 미래 날짜 → af 값 추종(startTime 만, 쌍둥이·겹침이면 보류). 팀 생성·매핑·삭제·병합은 자동으로 하지 않는다 — 9/24 에 표준 도구조차 Hajduk·Al-Ittihad 를 잘못 붙이려 했다.
- **알림은 "고칠 수 없는 것 + 고치다 포기한 것"만, 한 메시지로.** 이미 치유된 건 한 줄 요약. 같은 finding 은 24h 내 재알림 안 함.
- 매칭 규칙은 9/24 감사 스크립트에서 검증된 것(af 2,628경기 → 오탐 걸러 잔여 실누락만)을 그대로 옮긴다.
