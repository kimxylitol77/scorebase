# 컨텍스트 노트
- 2026-09-26 시작. 참고 이미지: transfermarkt 스쿼드 가치 랭킹·Squawka 드리블 TOP10·LiveScore 존별 성공/시도.
- 카드 크기 1080×1350(4:5) — `api/og/team-of-day` 와 같은 규격. 인스타·스레드 재사용 가능.
- 폰트는 `api/og/soccer-player` 와 같이 로컬 Noto Sans KR + Oswald 를 직접 로드(자동 글리프 의존 X).
- 수치는 `buildSoccerWeeklyReview`·`getWeeklyBestXi` 를 그대로 읽는다 — 글 본문과 카드 수치가 절대 어긋나지 않게(주간 리뷰 정합 원칙).
- 존별 드리블 카드(참고 3번)는 ts 매치 `playerStats` 에 dribble/dribble_succ 는 있으나 존 좌표가 없어 이번 범위 밖. 히트맵 JSON 은 시즌 단위라 주간 카드엔 부적합.
- `TodPlayer.logo` 는 선수 사진이고 팀 로고는 `WeeklyBestXi.logoByTeam[영문팀명]` — 처음에 팀 로고 자리에 얼굴이 들어가서 고침.
- satori 는 border 삼각형 트릭이 안 먹힌다(네모로 렌더). ▲▼ 글리프(Noto Sans KR 포함)로 대체.
- 카드 URL 은 `?league=&end=&kind=` 쿼리형. 팩트 게이트 정규식(`\d{1,2}[:대-]\d{1,2}`)에 날짜가 안 걸리는 건 확인했지만 삽입은 게이트 통과 뒤에 한다.
- dev 서버 첫 요청 때 홈 화면이 Neon 커넥션 풀(29)을 다 써서 카드가 폴백으로 떨어졌다 — 로컬 검증 시 홈 탭을 먼저 닫을 것. 운영은 CDN 캐시(1일)라 무관.
- 참고 이미지의 존별 드리블 카드는 이번 범위 밖(존 좌표 없음). 후보로 남김.
- 히트맵 카드(`kind=heat`): `src/lib/soccer/mvp-heat.ts` 가 `data/player-match-heatmaps.json` 에서 MVP 의 주간 창 경기 좌표를 뽑아 서버 KDE(32×20, sigma 6)로 격자화한다. satori 에 canvas·blur 가 없어 격자 div 로 그린다(임계 0.28·램프는 HeatPitch 와 동일). 3×3 존 비율은 원시 좌표로 따로 집계(격자 경계와 3등분이 안 맞아서).
- 경기 히트맵은 주간 백필 잡이 3주 SIGKILL 이라 9/4 까지만 있다(9/26 수정 32c57153). 창 안 좌표가 없으면 시즌 누적 셀(`player-heatmap-analysis.json`, 현재 대부분 1경기 고착)로 폴백하고 부제에 "시즌 누적 N경기 — 이번 주 좌표 미수집"을 박는다. 둘 다 없으면 잡이 히트맵 카드를 아예 안 넣는다(`hasMvpHeat`).
- 공급자 경기 날짜는 KST 보다 하루 빠를 수 있어 창 앞쪽 하루 여유. `[99,99]` 는 sentinel 로 제외.
- 야구 규정 타수는 12 로 두면 3경기 12타수 표본이 OPS 1위로 올라온다(손성빈 .500/1.488 실측) → 15. 투수는 ERA 동률이 많아(0.00 여럿) 이닝 → 탈삼진 순 타이브레이크.
- KBO 로그의 투수 `result` 가 비어 있는 경우가 있어(류현진 6이닝 무실점 0-0-0) 승패는 참고값. MLB 투수 games 는 스플릿에 없어 0 — 카드에 안 쓴다.
- StatTiles 를 flex 행 안에 넣을 땐 `width:100%` 필수 — 없으면 satori 가 자식을 0 폭으로 접어 라벨이 세로로 깨진다(첫 렌더 사고).
- NPB 팀 로고는 로그 약칭과 Team 표시명 포함 관계로 매칭. "DeNA"↔"요코하마" 만 별칭(라우트 TEAM_ALIAS). 로그 약칭 12개 실측: DeNA·닛폰햄·라쿠텐·롯데·세이부·소프트뱅크·야쿠르트·오릭스·요미우리·주니치·한신·히로시마.
- MLB 팀 주간(`mlb-weekly-*`)은 선수 카드 제외 — `mlb-players-weekly-*` 가 같은 데이터로 전용 글이라 이미지 URL 중복만 만든다.
- extractOgCardUrls 는 절대 URL(SITE_URL 붙은 순위 카드)도 상대 경로로 정규화 — 사이트맵·JSON-LD 가 `base + 상대` 로 조립하기 때문.
