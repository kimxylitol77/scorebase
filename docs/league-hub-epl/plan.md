# 리그 허브(/leagues/{league}) 를 리그 데이터의 메인으로

> 요청(2026-09-11): /leagues/EPL 을 메인으로 삼아 프리미어리그 데이터를 전부 여기서 보고, /predictions/EPL 도 여기서 갈 수 있게.

## 현재
- 허브는 이미 탭(순위·파워랭킹·일정·통계·역사·글)이 있다. 없는 것 = **예측**(우승·Top4·강등 확률) 과 다른 리그 데이터 페이지(순위표 정본·부상자·이적·오버언더·지난 시즌 결산)로 가는 한 곳의 입구.
- 시즌 시뮬레이션은 예측 페이지·홈 카드 2종이 각자 돌린다(시드 없음 → 페이지마다 ±1%p).

## 어떻게
1. `lib/predict/league-season-sim.ts` — `getLeagueSeasonSim(league)` 1h 캐시: 시즌 창(selectSeasonMatches) → 올스타 제외·NBA 30팀 → runMonteCarlo 5,000 → 일정 결손 가드. 예측 페이지·홈 카드 2종·허브 예측 탭이 **같은 캐시**를 읽어 어디서 보든 같은 숫자.
2. 허브 **예측 탭**(`?view=predictions`): 우승 확률·Top4(또는 포스트시즌)·강등 확률 요약 + 시즌 라벨 + "전체 시뮬레이션(예상 최종 순위·다가오는 경기 승률·리더보드) →" /predictions/{league}. 예측 지원 리그(PREDICTION_LEAGUES = 예측 페이지 VALID 를 lib 로 이동) 전부.
3. 허브 히어로: "시즌 예측 · 우승 확률" CTA(전 지원 리그) + **데이터 디렉터리** 칩 줄(순위표 정본·부상자·이적/몸값·오버언더·배당 흐름·지난 시즌 결산) — 그 리그에 실제로 있는 것만.
4. 예측 페이지 히어로에 "← {리그} 허브" 되돌아가기.
5. EN: /en/leagues 없음. 예측 페이지·홈 카드 미러만 재생성.

## 검증
- tsc·eslint. /leagues/EPL 예측 탭 렌더(우승 확률 상위·Top4·강등, 시즌 라벨), 허브 CTA·디렉터리 칩 링크 200 확인.
- /predictions/EPL 의 우승 확률 == 허브 예측 탭 == 홈 카드(같은 캐시). NBA/NHL(지난 시즌 폴백)·KBO(공용 캐시 시뮬 경로 유지)·UCL(리그 페이즈) 렌더.
