# 컨텍스트 노트 — 리그 허브 메인화
- **없애지 않고 입구를 모은다**: /standings/{lg}(순위 검색 정본)·/predictions/{lg}(시뮬 상세)는 각자 검색 의도가 있어 유지. 허브는 "요약 + 링크" 로 전부를 잇는다.
- **시뮬 캐시 통일이 핵심**: 몬테카를로에 시드가 없어 페이지마다 따로 돌리면 ±1%p 어긋난다(KBO 는 이미 getKboSeasonSim 공용 캐시). 허브 탭까지 세 곳이 되면 어긋남이 눈에 띄므로 리그 일반 경로도 1h 캐시로 통일. KBO(공용 캐시)·월드컵(토너먼트 시뮬)은 예측 페이지 고유 경로 유지.
- **홈 카드도 같은 캐시**: SeasonInsight 가 1,000회·SeasonInsightCard 가 5,000회를 ISR 마다 돌리던 것(리그 10개)을 캐시 조회로 — 홈 렌더 비용도 준다.
- **NBA 30팀 화이트리스트**는 예측 페이지에서 로더로 이동(같은 규칙).

## 2026-09-11 구현 결과
- 허브 탭 순서: 순위 · **예측** · 파워랭킹 · 일정 · 통계 · 역사 · 글. 비축구(NHL·LOL·NBA·KBO·MLB·NPB)와 컵(UCL·UEL·UECL·AFC_CL)에도 예측 탭. 히어로 CTA "시즌 예측 · 우승 확률 →" 는 허브 안 예측 탭으로, 상세는 탭 안 버튼과 디렉터리 칩 "시즌 예측 상세" 로.
- 디렉터리 칩(EPL 실측 6개): 순위표 전체 · 부상자 명단 · 이적·몸값 · 오버·언더 통계 · 배당 흐름 · 시즌 예측 상세. 오버·언더는 `leaguesWithOverUnderPage` 로 404 링크 방지, 이적은 /transfers 의 LEAGUES 키와 같은 9개 리그만.
- 예측 탭 상태 3갈래: 예정 0경기(시즌 종료·일정 미등록 — NBA/NHL 오프시즌·UCL 리그페이즈 미적재) / 완료 20경기 미만(분데스 18) / 정상(우승·Top4 또는 KBO 포스트시즌·강등 차트 3개). 지난 시즌 폴백은 "지난 시즌" 배지.
- 지난 시즌 결산 링크는 시즌 경계 있는 리그만·현재 시즌일 때만(/predictions/KBO/2025·/EPL/2025-26 은 200, NBA 는 폴백 중이라 생략 — 2024-25 는 404).
- EN: /en/leagues 없음. /en/predictions/[league] 미러를 재생성하니 KR 페이지에 뒤늦게 들어간 문구 8건(일정 결손 안내·MLS 서포터스 실드 등)이 한글로 새로 드러나 함께 번역했다 — 미러는 재생성 시점의 KR 을 그대로 따라오므로 오랫동안 안 돌린 라우트는 이런 잔여가 나온다.
- 렌더 실측(1280): 허브 EPL 예측 탭 차트 3개(맨시티·아스널·헐 시티 …), 예측 페이지 상단 "← 프리미어리그 허브".
