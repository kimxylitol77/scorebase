# /transfers 선수 종합 랭킹 — 컨텍스트 노트

## 실측 (2026-09-20)
- 빅5 활성 몸값 선수 3,890명. 이번 시즌(2026-07-01~) 경기 기록 있는 선수 2,157, 180분 이상 1,321, 평점 3경기 이상 1,789.
- 평점 중앙값 6.53, p90 7.18, p10 2.72 — 짧은 교체 출전에 낮은 평점이 붙어 단순 평균이 왜곡된다 → 분 가중 평균 사용.
- 몸값 이력은 선수당 평균 17.5 스냅샷, 1년 전 값 보유 3,801명(98%), 3년 전 3,558명. history 는 market_time 오름차순.
- PlayerMatchLog.playerId 와 PlayerMarketValue.id 는 둘 다 TheSports 선수 id → 조인 키 일치. 평점은 af 유래라 af 커버 리그(빅5·MLS·K리그 등)만 있다.

## 결정
- **저장 테이블·크론을 만들지 않는다.** 집계는 SQL group by 한 번(4천 명)이라 unstable_cache 6h 로 충분. 순위 변동 화살표가 필요해지면 그때 스냅샷 테이블 도입.
- **후보 풀은 몸값 표와 동일한 enriched(빅5·18개월 활성·중복 제거·이름 있음)**를 그대로 쓴다. 이름·팀·사진 표기가 몸값 표와 어긋나지 않게 하려는 것.
- **종합 지수 = 백분위 합성 100점.** 평점(분 가중)·90분당 골+도움은 포지션 그룹(공격·미드·수비·GK) 안에서 백분위, 출전 분·몸값(log)·1년 몸값 추세는 전체 풀 백분위. 가중치는 포지션 그룹별 표(lib 상단). 자격 = 180분 이상 + 평점 3경기 이상, 미달은 "표본 부족"으로 순위 제외.
- **유망주 = 21세 이하(age=23 토글), 90분 이상 출전.** 지수 = 몸값 백분위 50 + 평점 백분위 30(미평점은 중립 40점) + 출전 백분위 20, 나이 보정 ×(1+0.04×(21−나이)) 후 100 상한. 유망주 풀 안에서 백분위.
- **상승률 = (현재 − 1년 전) / 1년 전.** 1년 전 값은 now−365일 이전 마지막 스냅샷. 노이즈 컷 = 1년 전 1M 이상·현재 2M 이상. 서브칩으로 상승액·하락 전환.
- 새 라우트 대신 view 파라미터 확장 — 기존 URL·검색 자동완성·팀 드롭다운을 그대로 쓴다. 검색(q) 시 랭킹 뷰도 몸값 전체로 전환(기존 FEED_VIEWS 규칙과 동일).
- 필터바는 카테고리 칩 10개 한 줄 → "랭킹" 줄과 "이적시장" 줄. 리그별·팀별·국가별·포지션별은 몸값의 하위 칩으로 내려 URL(view=league 등)은 유지.

## 함정
- PmvRow 파생 캐시(getPmvRowsDefault)에 필드를 추가하면 배포 후 최대 30분 옛 형태가 남는다 → 캐시 키를 v2 로 바꿔 즉시 무효화.
- 유망주 나이는 PlayerMarketValue.age(스냅샷 시점) — 생일 지난 선수가 1살 어리게 남을 수 있다. 표시에만 쓰고 자격 판정도 이 값이라 경계(21/22)에서 한 명쯤 흔들릴 수 있음.

## 2단계 결정 (2026-09-20)
- **가성비 = 종합 지수 − 몸값 백분위(자격 풀 내 log 몸값).** "몸값 1M 당 골+도움"은 소액 선수가 무조건 이기는 지표라 버렸다. 그래도 3M 근처 베테랑(그로스·오바메양)이 상위인 건 정의상 맞는 결과. 몸값 3M 미만은 제외.
- **폼 = 최근 5경기(평점 있고 10분 이상 출전) 단순 평균.** 시즌 평균은 분 가중이라 "시즌 대비" 차이는 참고값. 0~9분 행에 붙는 1점대 평점이 콜드 랭킹 상위를 통째로 차지했던 것을 실측으로 잡음(슈쳉스니 1.00 등).
- **트로피 점수표는 lib 상단 TROPHY_POINTS.** Winner 만 집계, 유스·프리시즌·올스타는 정규식으로 0점, 미등재 시니어 대회는 1점. af 대회명 그대로 키라 이름이 바뀌면 1점으로 떨어진다(감시 없음). 표기는 trophyKo 로 주요 대회만 한글.
- **계약 만료 = data/player-contract.json(ts, 22,997명).** 대부분 6/30 자정(UTC+8) epoch. 범위는 "다음 여름 7/1 이전", 정렬은 몸값. 6개월 이하 빨강·12개월 이하 주황.
- 폼·계약 하위칩은 `g` 파라미터를 상승률과 공유(`g=cold`). 필터바 리그·포지션 칩은 현재 g 를 유지한다.
