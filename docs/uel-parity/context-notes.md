# UEL → UCL 급 승격 — 결정과 근거 (2026-07-30)

## 출발점

사용자 질문 두 개. "standings/UEL 자동 갱신되나", "라인업은 왜 안 올라오나". 실측해보니 둘 다 이미 되고 있었고, 진짜 격차는 다른 데 있었다.

- **순위**. 자동 갱신 맞다. TheSports 가 UEL standings 를 null 로 주기 때문에 `calc` 폴백(FINISHED 매치 자체 집계)으로 렌더된다. ISR 600초. 7월은 예선이라 UEFA 공식 리그 페이즈 표 자체가 없는 게 정상.
- **라인업**. 7월 24경기 중 13건(54%). 같은 기간 UCL 은 50경기 중 21건(42%)이라 **UEL 이 오히려 나았다**. 라인업은 문제가 아니었다.
- **진짜 격차**. UCL 은 있고 UEL 은 없는 코드 화이트리스트가 20곳. 예측 마켓·PREVIEW·ANALYSIS·적중률·GPT 비교·투표·푸터 전부.

## 근본 원인 — SPORT_PROFILE 누락

`SOCCER_LEAGUES_FOR_MARKETS` 에 UEL 을 넣어도 마켓이 안 나왔다. `getSportProfile('UEL')` 이 null 이었기 때문. 이게 UEL 의 predOverPick·predBttsPick 이 전부 0이던 진짜 이유다. 세트 편입과 프로파일 등록은 둘 다 필요하다.

프로파일 값은 짐작하지 않고 DB 289경기를 실측해서 정했다. 평균 2.64골(std 1.63)·평균마진 0.31(std 1.82)·O2.5 52.6%. 득점은 EPL(2.75) 수준이고 마진 분산만 조금 크다. → `overLine 2.5, totalStd 1.6, marginStd 1.8, handicapLine 0.5, homeBoost 1.1`.

## 표본 부족 극단 확률 — 발견과 대응

UEL 을 편입하자마자 라이브 페이지에 **핸디 99%·BTTS 100%·OVER 97%** 가 떴다. 근거는 단 한 경기(셰리프 0:5 마카비). 1경기 평균을 그대로 λ 로 쓰기 때문이다. UCL 예선도 원래 같은 상태였다 — UEL 편입으로 드러났을 뿐 신규 버그가 아니다.

세 가지를 시도했다.

1. **최소 표본 차단**(양 팀 2경기 미만이면 마켓 미표시). 극단은 사라지지만 9월 리그 페이즈 1~2라운드에도 마켓이 통째로 사라진다. UCL 최근 10경기 중 8건이 사라져 명백한 회귀. 기각.
2. **전 구간 shrinkage**(K=2). 마켓은 유지되나 표본 20경기 팀도 9%가 기준선으로 당겨져, 핸디 적중률이 평균 1.1%p 하락(SERIE_A 64.9→63.5). 기각.
3. **표본 5 미만에만 shrinkage** (채택). 쌓인 팀은 손대지 않고 예선·개막 초만 보정.

### 채택안 백테스트 (원본 → 적용 후)

| 리그 | OU | 핸디 | BTTS |
|---|---|---|---|
| EPL (n=370) | 54.6 → 55.1 | 59.7 → 60.0 | 56.2 → 55.4 |
| LALIGA (n=370) | 52.4 → 52.4 | 61.6 → 60.8 | 56.5 → 56.8 |
| SERIE_A (n=370) | 53.0 → 52.7 | 64.9 → 64.9 | 48.6 → 48.9 |
| UCL (n=186) | 59.1 → 59.1 | 59.7 → 57.0 | 48.4 → 50.5 |

모든 변화가 표준오차 안(n=370에서 ±2.5%p, n=186에서 ±3.6%p). 표본 수 n 이 그대로라는 게 중요하다 — 마켓이 사라지지 않았다는 뜻. UCL 핸디 -2.7%p 가 가장 크지만 노이즈 범위이고, 대신 UCL BTTS 는 +2.1%p 올랐다.

실제 화면 효과. 마카비 vs 셰리프 기준 핸디 99%→77%, OVER 97%→75%, 기대 총득점 5.5→3.6, 기대 마진 +5.5→+1.9.

## PREVIEW 는 왜 9월부터인가

`PREVIEW_LEAGUES` 에 UEL 을 넣었지만 7·8월 예선은 `isUefaQualifierMatch` 가 계속 막는다. "소국 클럽 예선은 검색 수요가 낮아 미발행"은 2026-06-03 사용자 결정이고 UCL 에도 똑같이 적용 중이라, parity 관점에서 그대로 뒀다. 9월 리그 페이즈부터 자동 발행된다.
