## 결정
- **KOVO 를 시즌 일정 정본으로 선적재**, ts 는 라이브·결과를 덧입힌다.
  ts 수집 라우트(thesports-matches)는 같은 리그·팀쌍(양방향)·±90분 안에 `ts-` 아닌 행이 있으면 새 행을 만들지 않고
  그 행에 TheSportsMatchCache 를 붙여 status·세트 스코어를 동기화한다(isTsSoleSource 에 배구 포함).
  배구 라이브 폴러 매핑(volleyball-matches-with-ts-mapping)도 cache 의 tsMatchId 를 먼저 본다 → KOVO 행이어도 라이브가 돈다.
- 10/31·11/1 ts 경기 시각·홈/원정이 KOVO 와 정확히 일치함을 확인(14:00·16:00 KST).
- externalId = `kovo-{시즌코드}-{gnum}`. gnum 은 시즌 안에서 남녀 통틀어 유일(남 홀수·여 짝수).
- raw 는 `{"kovo":{seasonCode,gnum,round,place}}` 만(작게).
- 이미 ts 행이 있는 경기는 만들지 않는다(같은 ±90분 팀쌍 규칙).
- 재실행 시 시작 전 경기의 킥오프 변경과 KOVO 결과 반영(FINISHED 역행 없음)만 한다.
- 일정 탭은 KHL·유럽 하키 경로(프리시즌 없음, 시즌 경계 없으면 8/1 부터)에 얹었다. 주차는 개막일(10/31) 기준 7일 단위.
