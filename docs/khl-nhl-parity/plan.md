## 1단계 (이번)
1. KHL SPORT_PROFILE — 이번 시즌 종료 경기 실측(총득점 평균·표준편차·마진 표준편차·홈 이점)으로.
2. KHL 예상 골리 — 팀별 최근 선발 골리(경기 캐시) + 시즌 선방률·GAA 를 homeGoalie/awayGoalie 에 저장. 경기 상세에 골리 카드("예상" 표기).
   예측 보정은 NHL 에서 튜닝된 값이라 KHL 에는 아직 안 건다(백테스트 전).
3. 리그 페이지 탭 — 파워랭킹(TeamPowerRanking)·선수 기록(리더보드).

## 2단계 (후속, 사용자 확인)
