# 축구 팀명 위키 검증 컨텍스트 노트

- 2026-07-19 시작. 요청 = "축구 팀명만 위키로 수정" (급여 선수명 위키 작업과 별개 세션, 그쪽은 건드리지 않음).
- 표시 체인 = team-names.ts 사전 > Team.nameKo(daily-official-korean 봇이 매일 덮어씀) > 영문.
  → 교정을 nameKo 에 하면 다음날 봇이 덮으므로 반드시 사전 파일에 한다 (schema.prisma Team.nameKo 주석과 동일 결론).
- 사전 규모 = RAW ~1,490쌍(alias 포함), 축구 섹션 판별은 `─── 섹션 ───` 주석 기준.
  제외 섹션 = NBA·WNBA·NHL·MLB·KBO·CPBL·LMB·월드컵 진출국·WORLD_CUP 보강(국가명)·K리그 커리어 경로(대학·실업).
- 판정 = 정확일치가 아니라 토큰 포함 대조. 사이트는 축약형("아스널")이고 위키 제목은 정식형("아스널 FC")이므로,
  사전 ko 토큰이 위키 ko 제목 토큰에 모두 포함되면 일치. 빠진 토큰이 있으면 불일치 후보로만 플래그(자동 치환 금지, 수동 검토).
  FC/CF/AFC/SC 등 접미 토큰과 괄호 병기는 대조 전 제거.
- 위키 조회 = en위키 titles 직조회(redirects=1) → " F.C."/" FC"/"(football club)" 접미 재시도 → intitle 검색 fallback.
  종목 가드 = description 에 football/soccer 요구(동명 도시·타종목 문서 오인 방지). ko langlink 없으면 보류(교정 불가, 현행 유지).
- 통용 표기 주의 = 위키가 항상 정답은 아님(사전 헤더 원칙 = 국립국어원+한국 미디어 관행). 3단계 검토에서
  "위키와 다르지만 미디어 통용"인 것(예. 도시명 관행)은 유지하고 명백한 음역 오류만 고친다.
