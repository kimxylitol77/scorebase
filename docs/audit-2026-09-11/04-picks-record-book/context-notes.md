# 컨텍스트 노트 — 과제 4 /picks 기록장
- **요구 1 은 이미 충족**: 컬럼명은 지시서의 `odds_at_pick`/`picked_at` 이 아니라 `MatchVote.pickOdds`/`createdAt`. 스키마를 바꾸지 않는다(기존 316표 데이터·CLV 파이프라인이 그 이름을 쓴다). 핸디·OU 는 시장 라인과 우리 라인이 같을 때만 배당을 인정(`pickOddsOf`) — 그래서 배당 없는 표가 생기고, 그게 "제외 N건" 의 정체다.
- **"배당 없음" 판정 = settleFlatUnits 의 excluded**: odds null 또는 1.01~30 밖. accuracy 의 이상치 규칙과 같은 값이라 세 화면이 같은 표본 규칙을 쓴다.
- **/lab 배당은 마감 배당**: Match.odds* 는 마지막 수집값(≈종가). 픽 시점 배당이 아니라 "마감 배당 기준 후행 시뮬" 로 라벨. 모델 쪽 유닛은 계산 불가(predCorrect 만 있고 모델 픽 방향이 피처에 없음) — 모델 대비는 기존 적중률 유지.
- **AI 비교 제거 원칙**: 적중 수 비교는 배당을 무시해 정배 픽이 유리하다. 대신 기준선 = 모델 픽 전체·시장 인기픽 플랫 ROI(roiClaim, 홈·meta 와 같은 캐시). 내 표본과 모델 표본이 달라 "이긴다/진다" 판정은 쓰지 않고 나란히 보여만 준다.
