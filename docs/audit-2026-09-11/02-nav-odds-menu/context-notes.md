# 컨텍스트 노트 — 과제 2 상단 네비 「배당」

## 2026-09-11 계획 시점 결정
- **기존 드롭다운은 CSS hover 전용**(`group-hover`) — 키보드·스크린리더로 열 수 없었다. 수용 기준 2 를 「배당」만 만족시키고
  나머지 메뉴는 hover 전용으로 두면 일관성이 깨지므로, 드롭다운 컴포넌트 하나를 고쳐 전 카테고리가 같이 좋아지게 한다.
  범위 확대가 아니라 같은 컴포넌트의 필연적 수정이다.
- **패턴**: 라벨은 `<Link>`(클릭 = 대표 페이지 이동) 그대로, 화살표를 `<button aria-expanded aria-controls>` 로 분리하는
  disclosure 패턴. 포커스만으로 열지 않는다(Escape 로 닫은 뒤 Tab 이 다시 열어 버리는 문제). `visibility:hidden` 인 패널의
  링크는 포커스 대상이 아니라 닫힌 상태에선 Tab 이 다음 메뉴로 넘어간다.
- **활성 판정**: `/odds*` 링크가 축구·야구·농구·배당 네 곳에 있다. 지시서가 「배당」을 정본으로 지정했으니 `owns` 접두 목록으로
  배당이 `/odds`·`/value-bets`·`/predictions/accuracy` 를 소유하고, 다른 카테고리는 소유 경로에서 활성이 되지 않게 한다.
  쿼리(`?sport=betman`)까지 대조하지 않는다 — `useSearchParams` 는 정적 라우트에서 Suspense 경계를 요구해 헤더 전체를
  건드리게 되고, 기준 3 은 카테고리 활성이라 경로만으로 충분하다.
- **위치**: 라이브 스코어 · 축구 · 야구 · 농구 · 기타종목 · **배당** · 커뮤니티 · AI 분석실. 종목 다음, 행동 기준 메뉴 첫 자리.
- **search/admin-structure/MenuFlowDiagram** 은 SPORT+COMMUNITY 만 명시적으로 쓰고 AI 분석실도 이미 빠져 있다 — 과제 범위 밖, 그대로 둔다.
- **영어판 헤더**는 드롭다운 없는 린 목록(6링크)이고 지시서가 KR 네비를 대상으로 해 건드리지 않는다.
