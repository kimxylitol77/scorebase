# 컨텍스트 노트 — 과제 1 후속 SEO·GEO
- **llms.txt 에 숫자를 쓰지 않는다**: 정적 파일이라 −3.8% 를 적으면 다음 채점부터 거짓이 된다. 페이지가 무엇을 공개하는지만 쓰고 숫자는 페이지로 보낸다.
- **FAQ 수익률 답은 claim 과 같은 소스**: 히어로·meta·FAQ 가 서로 다른 숫자를 말하면 GEO 에서 신뢰를 깎는다. `roiClaim()` 은 1h 캐시라 한 요청 안에서 셋이 같은 값.
- **`<title>` 은 유지**: 브랜드+카테고리 키워드("통계 기반 AI 스포츠 분석")가 검색 제목이라 바꾸지 않는다. og/twitter 제목만 주장으로.
- **Q4 는 부정문 유지**: "베팅 사이트가 아니다" 는 사실이고 정책(베팅 권유 X)이다. 다만 "배당과 무관" 은 이제 거짓이라 "중개·권유하지 않음 + 배당은 분석 대상" 으로 정확히 말한다.

## 2026-09-11 구현 결과
- 화면 FAQ(FaqSection)에도 같은 Q4 문구·수익률 Q 를 넣었다 — 구조화 데이터는 화면 내용과 일치해야 하고, 두 곳이 다른 문장을 쓰면 rich result 자격을 잃는다. `roiFaq()`·`FAQ_BETTING_ANSWER` 한 곳에서 만든다.
- dev 렌더 확인: KR og:title "스코어베이스 — 우리 픽의 수익률은 −3.8%, 시장 인기픽은 −6.6%", FAQ 5문항(Q5 수익률), 옛 "도박·베팅과는 무관" 문구 0건. EN 동일(verify 통과).
- `src/app/en/page.tsx` 의 eslint `react/no-unescaped-entities` 3건은 main 에 이미 있던 것(Today's 등 전역 사전 산출) — 이 과제와 무관해 건드리지 않았다.
- llms.txt 의 "GPT-5.5" 표기는 성적표 페이지의 "GPT-5.6" 과 다르다 — 범위 밖, 후속 메모.
