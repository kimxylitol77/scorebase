# 멀티픽 조합 카드 — 계획 (2026-09-13)

Dimers Parlay Picker 벤치마크. /picks/strong 의 고확신 픽을 2~3레그로 자동 조합해 카드로 보여준다.

**무엇.** 회원 화면 픽 목록 위에 "오늘의 조합" 카드 1~3개. 각 레그 = 기존 고확신 픽(리그·경기·픽·확신도·기준 초과폭), 조합 전체 확률 = 레그 확률의 곱, 실측 기대치 = 마켓별 실측 적중률의 곱. 지난 날짜는 레그 채점 결과로 조합 결과(전부 적중 → 적중)를 판정.

**왜 새 인프라가 없나.** 레그는 이미 채점되는 픽이라 조합 결과는 레그 결과의 AND 다. 저장·채점 잡 없음, 순수 조합 함수 하나.

**하지 않는 것.** 배당·수익률(우리 픽에 배당이 항상 붙지 않음), 사용자 조립 UI, 저장·공유.
