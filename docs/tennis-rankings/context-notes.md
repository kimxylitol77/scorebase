# 테니스 랭킹·선수 페이지 — 컨텍스트 노트

## 조사 결과 (2026-07-23 실측)

### ESPN 무료 가능/불가
- 가능: ATP·WTA 랭킹 150명씩(순위·포인트·등락 trend·국적·나이), 선수 프로필(신장·체중·주손·데뷔연도·출생지),
  시즌 통계(단식 승-패·타이틀·상금), 참가 대회 eventLog(55건), 매치·세트 스코어(구현 완료)
- 불가: 게임 포인트 라이브(15-40), 매치 summary(400), H2H, 드로우 대진표
  → TheSports 테니스는 미인가(유료 영업문의). Phase 2 로 미룸.

### 경쟁사
- Flashscore 한국어판이 실질 경쟁자(네이버 스포츠는 테니스 라이브스코어 사실상 없음).
  랭킹 탭 8종(ATP/WTA/레이스/복식) + 국적별 + 실시간 랭킹, 선수명·국적 완전 한글, 매치 H2H·통계.
- AiScore: 포인트 라이브 + 배당 3종. 둘 다 유료 소스 기반이라 무료로는 못 따라감.

### 한국 시장 판단
- **한국 선수가 ATP·WTA top150 에 전무** → 골프의 "한국 선수 강조" 전략이 테니스엔 무효.
  스타(시너·알카라스·조코비치)와 그랜드슬램 이벤트 중심으로 가야 함.
- 우리 차별점은 **한글명**. ESPN 원본은 영문이라 그대로 쓰면 Flashscore 하위호환.

## 결정
- 선수 한글명: 위키 ko langlink 커버리지 **21%(63/300)**, 상위 20위도 60% → 위키 단독 불가.
  기존 MLB·NBA 패턴대로 **위키 우선 + Haiku 음역 fallback** 정적 사전으로 간다.
- DB 수집 안 함: 테니스는 개인전이라 Match/Team 스키마와 안 맞고, 표시 전용으로 충분.
- 랭킹은 unstable_cache 로 충분(주 1회 갱신 데이터). 선수 상세는 core API 를 페이지에서 직접 fetch.

## 주의
- ESPN unofficial — 실패 시 graceful (랭킹 페이지가 죽으면 안 됨).
- WTA 는 headshot 없음(ATP 만 일부 존재) → 사진 의존 UI 금지.
- 선수 id 는 ESPN athlete id. 정적 사전 키도 id 기준으로 두면 동명이인 안전.
