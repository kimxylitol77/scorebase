# 헤더 메뉴 정리 + 종목 허브 기능 모음 — 계획

## 무엇을
1. 헤더 메뉴 54 → 34개. 같은 링크는 한 곳에만(리그 순위·배당 흐름·리그 전체), 14일 방문 한 자릿수 항목은 허브로.
2. 야구 포스트시즌 3개 → 메뉴 1개(KBO 기준) + MLB·KBO·NPB 페이지 상단 전환 탭.
3. 축구·야구·농구·하키 허브 헤더 아래에 "기능 모음" 섹션(묶음별 아이콘·이름·한 줄 설명). 페이지 맨 아래 이름만 나열된 칩 목록은 이 섹션으로 흡수·삭제.
4. /other 종목 카드에 빠진 링크(하키 스탯 표·LoL 스탯 표·리그 전체) 보강.

## 왜
메뉴가 과밀해 원하는 걸 찾기 어렵다(사용자 9/27). 7월 정리 원칙 — 메뉴에서 뺀 페이지는 다른 동선이 반드시 있어야 한다. 허브 칩 목록은 페이지 맨 아래·설명 없음이라 세부 기능이 안 보였다.

## 범위 밖
배당·커뮤니티·AI 분석실 메뉴(각 4~6개, 중복 없음). 허브의 리그 카드·오늘 경기 카드 구성.
