# scorebase 기능 인벤토리 (경쟁 분석 참조용)

## 정체성

- 한국향 **AI 스포츠 미디어** — scorebase.kr. 매일 매치 데이터를 자동 수집·분석·글 발행. 한국어 콘텐츠, 한국 사용자 타깃.

## AI 예측 (핵심 차별점)

- **5종 시장 예측**: 1X2(승무패), OU(오버/언더), 핸디캡, BTTS(양팀 득점), 더블찬스
- **적중률 실측 공개** — `/predictions/accuracy`, 13개 리그 동적 산출 (투명성이 차별점)
- **Strong Pick** — 확률 ≥65% 고신뢰 픽 별도 표기
- **시장 배당 블렌드** — 베팅사이트 평균 implied(vig 제거) 60% + 모델 40% 앙상블
- Elo 레이팅(FiveThirtyEight MoV), 몬테카를로 시즌 시뮬, 월드컵 토너먼트 시뮬 + 우승확률 추이 곡선
- 종목별 보정: MLB 선발투수 ERA/WHIP/K9, NHL 골리 GAA/SV%

## 콘텐츠 (자동 생성)

- **PREVIEW**(경기 전)·**RECAP**(경기 후)·**ANALYSIS**(주간 심층) 자동 글 — Claude 작성
- 이적시장 **위클리** 자동 발행 (빅5 + K리그1·사우디·MLS, 8개 리그)
- **감독 프로필** (경력·트로피·선호 포메이션)
- 데이터 블로그 (이적 가치·구단 가치 랭킹)

## 종목·리그 (12+)

- 축구: EPL·LALIGA·BUNDESLIGA·SERIE_A·LIGUE_1·MLS·UCL·WORLD_CUP
- 미국: NBA·NHL·MLB
- 한국/아시아: KBO·NPB
- 배구: VNL·AVC·EGL

## 데이터·페이지

- **라이브 스코어** (실시간, 점수 하향정정·VAR 반영)
- 라인업(축구)·선발투수(MLB)·골리(NHL), xG·모멘텀·H2H
- **순위표** (13개 리그)
- **선수 페이지** (시즌스탯, 연봉 랭킹 MLB/KBO, 한글명 음역)
- World Cup Best XI·예상 라인업, 선수 랭킹

## SEO·신뢰

- internal linking, AI 협업 명시(AiDisclosure), 외부 권위 출처(nofollow), JSON-LD(NewsArticle + SportsEvent)
- GSC 검색 성과 추적, 운영 봇 모니터링 생태계, AI 학습봇 차단

## 알려진 약점·미보유 (저들에 있고 우리에 없는 것 판단 기준)

- 선수 이름 한글화 부분적 — 영문 다수 잔존
- 샷맵·패스망·히트맵 등 **좌표 기반 시각화 없음** (데이터 소스 권한 한계)
- 커뮤니티/소셜/댓글 기능 약함
- 모바일 앱 없음, 동영상·하이라이트 없음
- 알림: 1:1 텔레그램 알림봇(경기 임박·결과·골, 팀·분석가 팔로우) 기구축 — 공개 방송 채널은 준비 중(코드 완료, 채널 개설 대기). 웹/앱 푸시는 없음
