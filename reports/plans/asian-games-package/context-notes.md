# 컨텍스트 노트
- ts 순위 API: 농구 season/table/detail 미인가, 배구·야구는 인가(조 이름 Group A… 있음). 야구는 "Winners stage"/"Losers stage" 2라운드 표도 준다.
- ts 단계: 농구만 match/season/recent 가 round.stage_id 를 준다(배구·야구 season/recent 미인가, diary 에 round 없음).
- 배구 여자 결선 첫날(9/20)에 8강 4경기 + 9~12위전 2경기가 섞인다 → 앞으로 세기는 틀린다. 끝난 대회는 결승(마지막 날 두 팀 모두 직전 결선 승리)에서 역추적.
- 진행 중인 배구 남자(10/1 8경기)는 대진표를 비운다 — 16강인지 순위전인지 원천으로 확정 불가.
- 초록(진출) = 대진표 첫 라운드 팀. "결선 경기에 나왔다"로 하면 순위전 팀까지 칠해진다.
- 농구 조 이름은 원천에 없어 첫 경기 순서로 1조부터.
- 결과 목록 dedupeFixtures 가 같은 홈·원정 72시간 재대결을 접어 야구 결승(9/27 일본 1-3 한국)이 사라졌다 → 둘 다 종료·점수 다르면 별개.
