# 전 리그 플레이오프 확률 (2026-09-30)

사용자: MLB 포스트시즌 확률판 배포 후 "다른 리그도 전부 만들어줘" → KBO·NPB, NHL·NBA, KHL·MLS, KBL 전부 선택.

엔진(src/lib/predict/playoff-sim): 남은 정규시즌을 Elo 로 샘플 → 리그 규정으로 시드 → 플레이오프를 경기 단위로 끝까지 샘플.
3,000회 반복, 팀별 "도달 단계" 분포를 낸다. 1h 캐시. MLB 는 이미 실제 대진 기반(mlbAdvancementOdds)이라 그대로.

형식(리그별 단계 = 표 열):
- KBO: 가을야구(5위) → 준PO → PO → KS → 우승. WC 4위 1승 어드밴티지(2경기 모두 4위 홈), 준PO·PO 5전, KS 7전.
- NPB: CS(리그별 3위) → CS 파이널(1위 1승 어드밴티지, 6전 4선승) → 일본시리즈 → 우승. 퍼스트 3전 전부 2위 홈.
- NHL: PO(지구 3위+WC 2) → 2R → 컨퍼런스 결승 → 스탠리컵 결승 → 우승. 지구 브래킷 고정, 홈=승점.
- NBA: PO(1~6 직행 + 플레이인 7~10) → 2R → 컨퍼런스 결승 → 파이널 → 우승. 1v8·4v5 / 2v7·3v6 고정.
- KHL: PO(컨퍼런스 8위) → 2R → 컨퍼런스 결승 → 가가린컵 결승 → 우승. 라운드마다 재시드.
- MLS: PO(컨퍼런스 9위, 8v9 단판) → 컨퍼런스 준결승(1R 3전2선승 통과) → 컨퍼런스 결승 → MLS컵 결승 → 우승. 단판 무승부=승부차기 50%.
- KBL: 6강 PO → 4강(1·2위 직행) → 챔피언결정전 → 우승. 5전·5전·7전.
