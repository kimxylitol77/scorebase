# 결정 기록

- CLV 의 "픽 시점"은 PREVIEW 글 발행 시각(publishedAt ?? createdAt) + 글에 저장된 predWinner. Match.predWinner 는
  갱신 시각이 없고 시장 60% 블렌드로 마감 배당을 따라가 순환 논리가 된다 → 쓰지 않음.
- 픽 배당 = 발행 시각 이전 마지막 OddsSnapshot(평균 배당), 마감 = 킥오프 이전 마지막 스냅샷. 발행 전 스냅샷 없는 글은 제외.
- CLV% = 픽 배당 / 마감 배당 − 1. 양수 = 마감보다 좋은 가격에 픽을 낸 것.
- 리그 범위는 ACCURACY_LEAGUES(적중률 페이지와 같은 16리그) — 페이지 간 표본 정의를 섞지 않는다.
- 실측(9/29, 전 리그 PREVIEW): 1,820픽, 마감보다 좋은 가격 920건(50.5%), 평균 +0.03%. 사실상 시장과 같은 수준 — 그대로 공개.
- "약한 리그" = headToHead 리그 행 중 표본 ≥50 이고 모델 적중 < 시장 적중.
