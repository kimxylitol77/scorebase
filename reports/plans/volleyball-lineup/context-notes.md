# V-리그 선발·예상 라인업 — 컨텍스트 노트

## 출발점 (2026-09-28)

사용자가 원더독스 중계 그래픽(전위 OP·MB·OH, 후위 OH·MB·S, 리베로)을 보여주며 "배구도 이런 라인업 되냐"고 물었다.
TheSports 배구 lineup 은 미인가(2026-09-20 실측). 대안으로 KOVO 기록지를 확인하기로 했다.

## KOVO 경기 상세 API (실측)

- 목록: `GET user-api.kovo.co.kr/stat/game-schedule?seasonCode=022&gender=2&leagueCode=201&page=0&size=N`
  - gender 1=남, 2=여. 항목에 gnum·hcode·acode·gdate·gstime·hspoint·aspoint·round.
- 상세: `GET /stat/game-schedule/{gnum}?gcode=001&seasonCode=022&leagueCode=201&round=1`
  - gcode=001 이 사이트 링크 값. gender·tcode 등 다른 조합은 404(사이트 번들엔 파라미터가 더 있지만 불필요).
  - payload = { game, player[], team[], ranking }.
  - player 행: tcode·pcode·pname·position(OP/OH/MB/S/L)·bnum(등번호)·ynCaptain·ynS1~ynS5·point 등 기록.
  - **ynS 코드**: `-1` = 그 세트 선발, `-2` = 결장, 숫자 N = 등번호 N 선수와 교체 투입.
    25-26 여자부 1번 경기 흥국생명: 세트1 `-1` 이 서채현S·최은지OH·김수지MB·이다현MB·정윤주OH·레베카OP + 박수연L = 6+1 로 맞아떨어짐.
- 코트 존(로테이션 시작 위치)은 주지 않는다 → 역할 기반 고정 배치로 그리고 "실제 로테이션 위치 아님"을 표시.

## 결정

- 우리 DB 에 V_LEAGUE/KOVO_CUP Match 가 아직 0건(수집기는 10월 개막 시 편입). 기능은 Match 가 들어오면 자동 노출되게 만들고,
  검증은 과거 KOVO 경기 + 로컬 임시 페이지로 한다.
- 예상 우선순위: 이번 시즌 직전 경기 선발 → (시즌 경기 없음) 현 로스터를 지난 정규시즌 출전 세트 수로 포지션별 정렬.
  직전 경기 선발은 부상·로테이션 변화를 반영 못 하지만 가장 흔한 예측법이고 설명하기 쉽다.
- 개막 전 로스터에는 외국인·아시아쿼터가 미등록(9/28 흥국생명 18명 전원 국내) → 빈 자리는 "미등록" 표시, 추측으로 채우지 않는다.
- KOVO컵 경기 매칭(시즌 코드 824 계열)은 이번 범위에서 제외 — 컵 경기도 예상(로스터 기반)은 나온다.
- 선수 사진은 로스터 image 를 pcode 로 붙인다(있을 때만).

## 검증 결과 (2026-09-28)

- 확정: 25-26 여자부 1번 경기 흥국생명·정관장 선발 7+7명이 기록지 수동 해석과 일치.
- 직전 경기: 가상 26-01-15 경기 → 흥국 1/14 vs 도로공사, 정관장 1/13 vs 페퍼 선발로 채워짐.
- 개막 전 예상: 14팀 전부 결과. OP 빈자리 5팀(외국인 미등록) → "?" + 안내문.
- 렌더: 375px 가로 넘침·말줄임 0, 라이트·다크 확인.
- 발견·수정: 과거 경기에서 이적 선수에게 새 팀 유니폼 사진이 붙었다(정호영) → 사진은 그 팀 현재 로스터일 때만.
