## KOVO 경기 상세 API (실측)

- 목록: `GET user-api.kovo.co.kr/stat/game-schedule?seasonCode=022&gender=2&leagueCode=201&page=0&size=N`
  - gender 1=남, 2=여. 항목에 gnum·hcode·acode·gdate·gstime·hspoint·aspoint·round.
- 상세: `GET /stat/game-schedule/{gnum}?gcode=001&seasonCode=022&leagueCode=201&round=1`
  - gcode=001 이 사이트 링크 값. gender·tcode 등 다른 조합은 404(사이트 번들엔 파라미터가 더 있지만 불필요).
  - payload = { game, player[], team[], ranking }.
  - player 행: tcode·pcode·pname·position(OP/OH/MB/S/L)·bnum(등번호)·ynCaptain·ynS1~ynS5·point 등 기록.
  - **ynS 코드**: `-1` = 그 세트 선발, `-2` = 결장, 숫자 N = 등번호 N 선수와 교체 투입.
    25-26 여자부 1번 경기 흥국생명: 세트1 `-1` 이 서채현S·최은지OH·김수지MB·이다현MB·정윤주OH·레베카OP + 박수연L = 6+1 로 맞아떨어짐.
- 코트 존(로테이션 시작 위치)은 주지 않는다 → 역할 기반 고정 배치로 그리고 "실제 로테이션 위치 아님"을 표시.

## KOVO컵 기록지 연결 (2026-09-28)

- 컵 시즌 코드는 `season-list?gcode=002` 의 ryear 로 찾는다(2025=823, 2026=824). 일정은 leagueCode 없이 받는다
  (조별리그 212·준결승 213·결승 214 혼재). 기록지 상세는 gcode=002 + 경기별 leagueCode 여야 200(001 은 404).
- 컵 + 정규리그를 한 목록으로 합쳐, 컵 경기는 종료 후 실제 선발, 정규리그 개막전은 컵 직전 경기 선발이 예상이 된다.
- 실제 선발 6명이 등록 포지션상 코트 배치와 어긋날 수 있다(2025컵 GS칼텍스 OP 없이 OH 3명) → 빈 자리를 남은 선수로 채우고,
  마커 라벨은 자리 이름이 아니라 선수 본인 등록 포지션으로 표시(사실과 다른 "OP" 표기 방지).
