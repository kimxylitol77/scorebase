# V-리그 선발·예상 라인업 (코트 배치) 체크리스트

> 목표. V-리그·KOVO컵 경기 상세에 TV 중계 그래픽처럼 양 팀 선발 6인 + 리베로를 코트 위에 배치해 보여준다.
> 경기 종료 후에는 실제 선발, 경기 전에는 예상 선발을 쓴다. 근거와 결정은 context-notes.md 에 있다.

## 계획

1. KOVO 경기 상세 API 에서 세트1 선발을 뽑는 lib 작성 → 검증: 25-26 여자부 1번 경기(흥국생명-정관장) 선발이 수동 확인값과 일치.
2. 예상 로직(직전 경기 선발 → 없으면 로스터+지난 시즌 출전 세트) → 검증: 2026-27 개막 전 14팀 전부 결과가 나온다.
3. 코트 배치 컴포넌트 + 배구 경기 상세 배선 → 검증: 로컬 렌더로 모바일(375)·데스크톱·다크 확인.
