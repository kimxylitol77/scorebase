- 두 리뷰(긴 지시문 + 배터 리포트 HTML, 2026-08-22) 대조. 리뷰 오판 2건은 제외

## 결정
- **배당 셀 라벨** — `OddsCell` 에 승/무/패·O/U 기준선 라벨, `MatchOdds.updatedAt`(= `oddsBookmakers.updatedAt`, 추가 쿼리 0)·`trend`(첫 OddsSnapshot 대비 ±2% 초과만, 5분 캐시 1쿼리). "지연" 임계는 6h — 목록 배당은 cron 평균값이라 LiveOddsCard 의 30분 기준을 쓰면 전부 지연으로 찍힌다. 상대시각은 mount 후 계산(hydration 함정).
- **버튼** — 예측/L/R → 분석/라인업/리뷰 + aria-label. 정보 칸 48→84px, globals.css 1·2단계 컨테이너 경계 +36px 동반 이동(970→1006·845→881·800→836·680→716). 다른 사본 없음(grep 확인). 헤더 컴포넌트 `SoccerLiveRowHeader` 는 미사용이지만 템플릿만 맞춤.
- **사이드바** — 이미 "오늘 경기 있는 리그"만 나오므로 평면 "오늘" 구획은 국가별과 100% 중복. 구획을 서로소로 설계: 즐겨찾기 → 인기 → 오늘 경기 많은 리그(상위 8) → 국가별(나머지, `<details>` 기본 접힘, 활성 리그 국가만 자동 펼침) + 검색. 즐겨찾기 리그 저장소는 없었음 → `useFavoriteLeagues`(localStorage `scorebase:fav-leagues`) 신설, 계정 동기화는 미적용. SSR 은 즐겨찾기 빈 상태로 나가고 hydration 후 채워짐(사이드바 한정 이동, 본문 점프 없음). 모바일은 사이드바 자체가 hidden 이라 영향 없음.
- **푸터** — "도박·베팅과 무관" 은 배당·밸류베트와 자기모순(리뷰 T3). "베팅 서비스 제공·권유 안 함 + 합법 사업자 한정 + 19세 + 1336(kcgp.or.kr)" 로 교체. picks/strong·lab·landing·ai-sports-prediction 의 같은 문구도 동일 톤으로. prompts/*.ts 는 LLM 지시문이라 미수정.
- **퍼센트** — 리뷰가 본 0.174/0.391 은 경기 상세 "핵심 변수 → 시즌 승률"(live/[league]/[gameId]·live/lol). 야구·농구 `.612` 승률과 Brier 는 도메인 관례라 유지.
- **검증(8/22)** — dev 서버 실렌더: 배당 셀 scrollWidth==154(넘침 없음), 정보 칸 84 딱 맞음, 국가별 69개 전부 접힘, 즐겨찾기 토글 → 구획 이동·인기에서 제거 확인, 검색 "일본"→J1·J2, hover 팝업(19곳 평균·갱신 1시간 전·▲▼), 모바일 375px 가로 넘침 없음. **미검증**: 경기 상세 퍼센트·푸터 실렌더(운영 DB 부하로 사용자 요청에 따라 dev 중단, curl 은 000). tsc 통과.
- dev 서버가 운영 Neon 을 같이 써서 커넥션 풀 타임아웃 유발 — 접속 많은 시간대엔 로컬 렌더 검증 자제.
